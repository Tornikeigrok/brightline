# BrightLine — Task Management App

A full-stack project management and task tracking application built with React, TypeScript, and Vite.

## Features

- Project & task management
- Real-time collaboration with team members
- Calendar view with deadlines
- Analytics dashboard
- Notifications & invitations
- AI-powered calendar suggestions

## How to Run Locally

### Prerequisites
- [Node.js](https://nodejs.org/) (v18 or higher)
- Backend server running on port 4000

### Steps

1. Clone the repository
   ```bash
   git clone https://github.com/Tornikeigrok/brightline.git
   cd brightline
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Start the development server
   ```bash
   npm run dev
   ```

4. Open your browser and go to:
   ```
   http://localhost:5173
   ```

> Note: The backend API must be running on `http://localhost:4000` for login and data features to work.

## Tech Stack

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Socket.IO (real-time features)
- React Router
